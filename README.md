# FATODEL Station Hub

FATODEL Station Hub is a fuel station management system designed to simplify daily station operations, record fuel sales and expenses, and monitor financial performance across multiple stations.

## Features

- Role-based access for Admin and Managers.
- Station and manager management.
- Daily fuel sales records for Pump 1 and Pump 2.
- Attendant tracking for each pump.
- Daily sales, expenses, and net amount calculations.
- Monthly financial records and reports.
- Excel export functionality.
- Dashboard for monitoring station performance.
- Secure authentication and password management.

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Frontend:** HTML, CSS, JavaScript
- **Authentication:** JSON Web Token (JWT)

## Project Structure

- `Backend/` – API, authentication, business logic, and database operations.
- `Frontend/` – User interface and client-side functionality.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/CODWRD/Fatodel-Station.git
   ```

2. Navigate to the backend directory:

   ```bash
   cd Fatodel-Station/Backend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your environment variables in a `.env` or `config.env` file.

5. Start the server:

   ```bash
   npm run dev
   ```

## Purpose

FATODEL Station Hub aims to improve fuel station management through organized record-keeping, financial tracking, and centralized station administration.
